# 🌅 早间要闻 — 2026-11-02 15:07

## 📋 今日概述

今日要闻集中在量子纠错（QEC）的工程化与容错量子计算资源优化两条主线：FPGA 实时 BP 解码器首次在高速率 [[512,174,8]] qLDPC 码上达到 BP+OSD-CS₁₀/Relay-BP 精度并满足中性原子延迟预算，同时基于搜索知识蒸馏的 GraphMP 解码器实现了跨码族、码长与噪声模型的免微调迁移，标志着 QEC 解码正从算法验证走向可部署、可泛化的实时系统。GKP 态制备方面，时域复用降低每模光子数分辨需求，损耗感知优化以压缩度为指标提升态鲁棒性，二者共同指向光量子架构中“资源—损耗”权衡的精细化设计。对专业研究人员而言，这意味着解码器设计需同时兼顾延迟、精度与跨场景泛化，而 GKP 相关工作提示应将损耗纳入态制备与架构协同优化的核心约束；eCAS 轨道嵌入则从算法侧为容错量子化学应用压缩资源开销，值得与上述硬件进展联动评估。

## 🔬 影响力论文

### 1. Time-Domain Multiplexing for Resource-Efficient Heralded GKP State Preparation

**来源**: arXiv quant-ph  
**时间**: 2小时前  
**链接**: https://arxiv.org/abs/2610.41341  

通过时域复用将预报光子分散到更多测量模式，减少每模光子数分辨需求，避免全压缩空间架构中同时运行过多压缩源的问题。

### 2. Real-time BP decoding of a high-rate QEC code

**来源**: arXiv quant-ph  
**时间**: 2小时前  
**链接**: https://arxiv.org/abs/2610.41413  

FPGA实时解码器实现高速率[[512,174,8]]三维乘积qLDPC码，单核达BP+OSD-CS₁₀精度、三核达Relay-BP精度，满足中性原子延迟预算。

### 3. Distilling Knowledge from Search: Decoder Model Factory for Quantum LDPC Codes

**来源**: arXiv quant-ph  
**时间**: 2小时前  
**链接**: https://arxiv.org/abs/2610.41398  

基于搜索知识蒸馏的GraphMP解码器实现量子LDPC码跨码族、码长、物理错误率和噪声模型的免微调迁移，以局部消息传递保持可扩展性，并用束搜索逐步优化候选错误模式以降低逻辑错误率。

### 4. Loss-aware optimization of realistic GKP gid states

**来源**: arXiv quant-ph  
**时间**: 2小时前  
**链接**: https://arxiv.org/abs/2610.41388  

针对光子损耗不可避免的问题，提出基于GKP基态表示的损耗感知优化方法，以压缩度为操作指标，制备出更鲁棒的GKP量子态，降低损耗的负面影响。

### 5. eCAS: An Orbital Embedding Method for Quantum Computing

**来源**: arXiv quant-ph  
**时间**: 2小时前  
**链接**: https://arxiv.org/abs/2610.41517  

提出eCAS轨道嵌入方法，通过划分量子系统降低第二量子化电子哈密顿量的项数规模，以支持未来容错量子计算机计算原子体系电子结构。
